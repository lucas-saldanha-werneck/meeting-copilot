Set up this phone

This phone will trust a certificate authority that can vouch only for __NAME__ and home network addresses (192.168.x.x, 10.x.x.x, 172.16-31.x.x). It cannot vouch for any other site.

iPhone or iPad

Download the profile

  1. Tap Allow when Safari asks to download a configuration profile.
  2. Open Settings: tap Profile Downloaded (at the top), then Install, and confirm. iOS says "Not Signed": that is expected.
  3. Then Settings, General, About, Certificate Trust Settings: turn on "Meeting Copilot CA (__NAME__)".

Android

Download the certificate

  1. Settings, Security (or Security and privacy), Encryption and credentials (or More security settings).
  2. Install a certificate, then CA certificate, accept the warning, and pick the downloaded file.

The exact menu names differ between phones.
